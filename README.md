# Шахматный помощник

Оверлей поверх любых окон: анализ позиции движком Stockfish, разбор партий по PGN,
дебютный репертуар, захват области доски под будущее распознавание.

## Запуск

Ярлык на рабочем столе «Шахматный помощник» или `run.bat`.

Первый запуск на новом компьютере — `setup.bat` (создаст окружение, поставит
зависимости и скачает Stockfish).

## Что внутри

| Папка / файл | Назначение |
|---|---|
| `main.py`, `app\` | код приложения |
| `engine\stockfish.exe` | движок Stockfish 19 (скачан, ~103 МБ) |
| `data\repertoire\` | сюда кидать PGN-репертуар: имя файла = название дебюта |
| `reports\` | отчёты по партиям и снимки области доски |
| `phone\` | веб-шахматы для телефона (сервер + страница) |
| `run-phone.bat` | запуск шахмат для телефона |
| `ПРОВЕРКА.md` | чек-лист ручной проверки |
| `.venv\` | виртуальное окружение Python |
| `settings.json` | настройки окна, глубины, области захвата (создаётся сам) |
| `MANIFEST.json` | список всего скачанного/установленного — по нему работает удаление |

## Как пользоваться

**Анализ.** Вставь FEN (или скопируй из chess.com/Lichess) → «Применить FEN».
Движок считает сам, если включена галочка «Сразу анализировать». Показывает 1–5 лучших
линий, оценку и главный вариант.

**Партия.** «Открыть PGN» или «Из буфера» (скопированная на chess.com партия:
Share → PGN) → «Разобрать партию». На выходе таблица ходов с оценкой,
потерей в пешках и пометками `?`, `??`, `?!`, `✓`. Отчёт сохраняется в `reports\`.

**Дебют.** Положи PGN в `data\repertoire\` → «Обновить». Выбери дебют в списке —
для текущей позиции будет показан книжный ход с частотой. «Сделать книжный ход»
проигрывает его по доске помощника.

**Экран.** «Выбрать область мышью» → обведи доску в приложении chess.com. Снимок
кладётся в `reports\capture.png` (по нему настраивается распознавание фигур).

**Камера (телефон над доской).** На телефоне поставь IP Webcam или DroidCam, узнай URL
потока и введи его во вкладке «Камера»:
```
IP Webcam:  http://192.168.x.x:8080/video
DroidCam:   http://192.168.x.x:4747/video
```

Дальше: «Подключить» → кликни 4 угла доски по часовой стрелке от a8 (левый верхний
угол со стороны камеры) → h8 → h1 → a1 → «Проверить сетку». Если жёлтые линии лежат
по краям клеток — калибровка верная. «Сохранить клетки» выгружает 64 клетки в
`reports\squares\` (по ним настраивается распознавание фигур).

## Шахматы на телефоне

`run-phone.bat` или ярлык **«Шахматы на телефоне»** → в консоли появится адрес вида
`http://192.168.x.x:8000` → открыть его в браузере телефона (телефон и ПК в одной Wi-Fi).
ПК считает Stockfish, телефон только показывает доску.

- уровень 1–20 и выбор цвета
- «Подсказка» — лучший ход, оценка и главный вариант
- «Ход за меня» — движок играет твой ход на максимуме, соперник отвечает сразу
- «Назад», «Новая»

API: `/api/new`, `/api/move`, `/api/hint`, `/api/bot`, `/api/position`.

Если Windows спросит про доступ к сети — разреши для **частных сетей**, иначе телефон
не увидит ПК.

## Важно

Оверлей сделан для анализа, обучения и разбора своих партий. Автоматическая игра
кликами в живой партии на chess.com/Lichess — нарушение правил сайта (бан аккаунта),
поэтому такой функции здесь нет: движок играет только на локальной доске помощника.

## Требования

- Windows 10/11
- Python 3.10+
- около 250 МБ на диске (окружение + Stockfish)

Всё остальное `setup.bat` поставит сам: PySide6, python-chess, OpenCV, mss, Pillow
и Stockfish 19. На некоторых провайдерах `pypi.org` недоступен — в `setup.ps1`
прописаны зеркала (в том числе Tsinghua) с автоматическим перебором.

## Установка из репозитория

```
git clone https://github.com/FastNaLast/ChessHelper.git
cd ChessHelper
setup.bat
run.bat
```

## Удалить всё скачанное

```
powershell -ExecutionPolicy Bypass -File tools\uninstall.ps1
```

Удаляет `.venv`, `engine`, кэши. Код, `data` и `reports` остаются.

## Перенос на новый компьютер

```
powershell -ExecutionPolicy Bypass -File tools\backup.ps1
```

Получишь zip на рабочем столе без `.venv` и `engine`. На новом ПК: распаковать →
`setup.bat`. Либо скопировать всю папку целиком, кроме `.venv` (её надо пересоздать).
